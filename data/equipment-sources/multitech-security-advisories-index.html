Reporting an Issue:

To report a suspected security issue in a MultiTech device or operating system, visit the MultiTech Product Support Portal

  1. Log into your account or register for a new account
  2. Create a new case
  3. For Service Requested, select Product Security
  4. In the Description, please include the following information, if available:
      1. Vulnerability type (buffer overflow, integer overflow, …)
      2. Issue impact (arbitrary code execution, information disclosure, …)
      3. Affected product and version
      4. Instructions to reproduce the issue
      5. A proof-of-concept (PoC), if available
